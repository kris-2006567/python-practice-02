# Конвертер единиц измерения (v2.0)

## Назначение проекта
Программа переводит значения из одних единиц измерения в другие.
Работает в консольном режиме (терминал).

## Какие задачи решает программа
Программа умеет переводить:
1. Градусы Цельсия → Градусы Фаренгейта
2. Километры → Мили
3. Килограммы → Фунты
4. Метры → Футы
5. Литры → Галлоны (НОВОЕ)
6. Мегабайты → Гигабайты (НОВОЕ)

**Новый функционал:** теперь можно выполнять несколько преобразований подряд, не перезапуская программу.

## Инструкция по запуску
1. Установите Python.
2. Откройте файл main.py.
3. Нажмите F5.

## Пример работы
Выберите конвертер:
1. Градус Цельсия -> Градус Фаренгейта
...
Ваш выбор: 2
Введите километры: 10
10.0 км = 6.21 миль
