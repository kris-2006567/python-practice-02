# Конвертер единиц измерения

## Назначение проекта
Программа переводит значения из одних единиц измерения в другие.
Работает в консольном режиме (терминал).

## Какие задачи решает программа
Программа умеет переводить:
1. Градусы Цельсия → Градусы Фаренгейта
2. Километры → Мили
3. Килограммы → Фунты
4. Метры → Футы

## Инструкция по запуску
1. Установите Python 3.10 или новее с https://www.python.org/
2. Скачайте файл converter.py
3. Откройте файл в IDLE
4. Нажмите F5 (или Run → Run Module)

## Как пользоваться программой
1. Запустите программу
2. Выберите номер конвертера (от 1 до 4)
3. Введите значение для перевода
4. Получите результат

## Пример работы программы
Выберите конвертер:
1. Градус Цельсия -> Градус Фаренгейта
2. Километры -> Мили
3. Килограммы -> Фунты
4. Метры -> Футы
Ваш выбор: 1
Введите температуру: 36
36.0 C = 96.8 F

## Обработка ошибок
- Если ввести номер не от 1 до 4 — программа сообщит об ошибке
- Если ввести букву вместо числа — программа сообщит об ошибке
