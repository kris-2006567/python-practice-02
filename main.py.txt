# ПРАКТИЧЕСКАЯ РАБОТА 1. ВАРИАНТ 2. КОНВЕРТЕР ЕДИНИЦ
# Программа переводит единицы измерения

#Вывод меню для пользователя
print("Выберите конвертер:")
print("1. Градус Цельсия -> Градус Фаренгейта")
print("2. Километры -> Мили")
print("3. Килограммы -> Фунты")
print("4. Метры -> Футы")

#Получение номера конвертера от пользователя
# try — пытаемся выполнить код
try:
    # int превращает текст в целое число
    # input ждёт ввода с клавиатуры
    vibor = int(input("Ваш выбор: "))
    
    #Проверка номера и ввод значения
    if vibor == 1:
        #Ввод температуры
        c = float(input("Введите температуру: "))
        #Формула перевода: F = C * 9/5 + 32
        f = c * 9 / 5 + 32
        #Вывод результата
        print(c, "C =", f, "F")
    
    elif vibor == 2:
        #Ввод километров
        km = float(input("Введите километры: "))
        #1 км = 0.621371 мили
        mili = km * 0.621371
        print(km, "км =", mili, "миль")
    
    elif vibor == 3:
        #Ввод килограммов
        kg = float(input("Введите килограммы: "))
        #1 кг = 2.20462 фунта
        funty = kg * 2.20462
        print(kg, "кг =", funty, "фунтов")
    
    elif vibor == 4:
        #Ввод метров
        m = float(input("Введите метры: "))
        #1 м = 3.28084 фута
        futy = m * 3.28084
        print(m, "м =", futy, "футов")
    
    else:
        #Если номер не 1-4 — ошибка
        print("Ошибка: неизвестный номер преобразования")

# except — что делать, если была ошибка
except ValueError:
    #ValueError возникает, если пользователь ввёл не число
    print("Ошибка: нужно ввести число")
